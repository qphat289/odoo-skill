# Odoo Development Workspace

Use this repository in Claude Code as an Odoo skill-pack workspace.

## Canonical instruction

Use `AGENTS.md` as the canonical repository instruction file, then follow its workflow.

## Host note

Opening this repository loads `CLAUDE.md`, but that alone does not register every helper file as a native Claude feature.

## Setup note

Native Claude skills must still live under `.claude/skills/<name>/SKILL.md` or a plugin `skills/<name>/SKILL.md` layout when you are doing a native install.
